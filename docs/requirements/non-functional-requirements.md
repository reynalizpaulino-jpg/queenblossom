# Requisitos no funcionales – Queen Blossom

## 1. Introducción

Los requisitos no funcionales establecen las condiciones de calidad que deberá cumplir Queen Blossom para ofrecer una experiencia de compra segura, rápida y sencilla.

A diferencia de los requisitos funcionales, que indican las acciones que podrá realizar el sistema, estos requisitos describen cómo debe funcionar la plataforma y qué condiciones debe cumplir durante su utilización.

Los siguientes requisitos fueron identificados durante la etapa de análisis del proyecto en la asignatura Ingeniería de Software I.

## 2. Requisitos no funcionales

### RNF-01. Facilidad de uso

**Prioridad:** Alta

La interfaz de Queen Blossom debe ser clara, organizada y fácil de utilizar para los clientes.

**Criterio de aceptación:** Los botones, menús y opciones principales deben identificarse fácilmente y utilizar nombres comprensibles.

### RNF-02. Rendimiento del sistema

**Prioridad:** Media

Las pantallas principales del sistema deben cargar en un tiempo razonable para evitar esperas innecesarias durante la navegación.

**Criterio de aceptación:** El catálogo y las pantallas principales deben cargar en un máximo aproximado de tres segundos bajo condiciones normales de funcionamiento.

### RNF-03. Seguridad de acceso

**Prioridad:** Alta

El sistema debe proteger la información de los usuarios y evitar el acceso no autorizado a sus cuentas.

**Criterio de aceptación:** Las contraseñas deben permanecer ocultas durante su escritura y no debe permitirse el acceso con credenciales incorrectas.

### RNF-04. Adaptabilidad a diferentes dispositivos

**Prioridad:** Media

La interfaz debe adaptarse correctamente a computadoras, tabletas y teléfonos móviles.

**Criterio de aceptación:** Las funciones principales deben poder utilizarse en diferentes tamaños de pantalla sin perder información ni presentar problemas importantes de visualización.

### RNF-05. Compatibilidad con navegadores

**Prioridad:** Media

Queen Blossom debe funcionar correctamente en los navegadores web de uso común.

**Criterio de aceptación:** Las funciones principales deben probarse sin errores graves en Google Chrome, Microsoft Edge y Mozilla Firefox.

## 3. Relación con la calidad del sistema

Estos cinco requisitos permiten establecer las condiciones necesarias para que Queen Blossom no solamente cumpla sus funciones principales, sino que también ofrezca una experiencia adecuada a sus usuarios.

La facilidad de uso ayudará a que los clientes puedan navegar por la tienda sin complicaciones. El rendimiento permitirá que las páginas carguen en un tiempo razonable, mientras que la seguridad buscará proteger el acceso a las cuentas.

Asimismo, la adaptabilidad y la compatibilidad permitirán que el sistema pueda utilizarse desde diferentes dispositivos y navegadores.

## 4. Estado actual

Los cinco requisitos no funcionales se encuentran definidos y documentados como parte del análisis inicial de Queen Blossom.

Su cumplimiento deberá comprobarse mediante pruebas de funcionamiento, seguridad, rendimiento y compatibilidad cuando las funcionalidades correspondientes estén implementadas.

## 5. Conclusión

La definición de los requisitos no funcionales constituye una parte importante de la planificación de Queen Blossom, ya que permite identificar las condiciones de calidad que deberá cumplir la tienda virtual.

Estos requisitos servirán como referencia durante el desarrollo y las pruebas del sistema, ayudando a detectar posibles dificultades y orientar las mejoras necesarias.
